State 1

Default / Idle

Standard call-to-action appearance. Bold contrast with white typography and Haitian brand red.

State 2

Hover / Focused

Triggered on mouseover or keyboard focus. Darkened shade with subtle elevation and tactile shadow.

State 3

Processing / Loading

Active server verification in flight. Button prevents duplicate submissions and displays an SVG spinner.

State 4

Success / Confirmed

Funds allocated and covenant signed. Button shifts to sovereign green with checkmark before redirect.

State 5

Disabled / Incomplete Form

Shown when mandatory inputs (CVV, Card number, Agreement checkbox) remain incomplete.
